# 剧集查重（影视目录重整分流）插件说明与操作指南

## 一、插件定位与设计原理

本插件（`media.series-dedup`）针对多盘挂载（如 HTTP 分享挂载与 CloudNAS 本地挂载）、多库影视并存场景，提供基于 TMDB 官方权威数据的目录比对、重复识别与安全重整分流：

1. **TMDB ID 聚合归组**：
   - 遍历媒体库目录，精准解析目录名中的 `{tmdb-xxxxx}` 标识。
   - 将相同 TMDB ID 的所有目录归入同一作品组，识别出在同一库或跨库存在的重复目录（≥2 个目录）。

2. **STRM 链接识别与混合链保护**：
   - 读取目录下 `.strm` 首行链接：
     - 若为 `http://...` 或 `https://...`，判定为 `http` 分享链。
     - 若为 `/...` 本地路径，判定为 `cloudnas` 本地链。
     - 若同一目录下既有 `http` 又有本地文件，标记为 `mixed` 混合链。
   - **拦截保护**：凡涉及 `mixed` 混合链的目录，插件绝不自动分配方案或投递整理，严格保证数据安全。

3. **TMDB 权威缓存强制同步与清洗比对**：
   - 处理前通过 MT 官方接口强制同步最新 TMDB 缓存（消除本地陈旧缓存）。
   - 过滤本地目录名中的零宽不可见字符（`\u200b`~`\u200f`, `\ufeff` 等），将本地片名与年份与 TMDB 官方最新片名及年份进行全等比对。
   - 发现片名或年份不一致时，标记为待重整目录，并记录具体差异原因。

4. **双轨智能分流建议与投递**：
   - 电视剧分类（或识别为非电影的影视）：
     - `http` 链接建议走 **本地整理**（本地整理方案，目标路径按实际库配置）。
     - `cloudnas` 链接建议走 **云盘整理**（云盘整理方案，目标路径按实际库配置）。
   - 电影分类同样对应至电影的独立方案。
   - 提供只读调试模式（`debugMode` 开关），默认为模拟日志，必须显式确认方可实机投递。

## 二、目录结构

```
media.series-dedup/
├── core/
│   ├── __init__.py
│   ├── scanner.py        # 目录扫描、TMDB ID 提取、strm 首行解析
│   ├── tmdb.py           # MT TMDB 缓存读取与强制同步
│   ├── matcher.py        # 零宽字符过滤、片名/年份全等比对、冲突分析
│   └── submitter.py      # MT 方案分流与整理任务投递
├── ui/
│   └── icon.png          # 插件图标
├── tools/
│   ├── pack_local.py     # 本地标准打包脚本
│   └── deploy.py         # 自动打包、上传与动态授权部署脚本
├── tests/
│   └── test_dedup.py     # 核心功能单元测试
├── docs/
│   └── 插件说明与操作指南.md # 本文档
├── plugin.json           # 动作、查询与权限声明
├── plugin.py             # 声明式 MT UI v2 页面与动作处理
├── pyproject.toml        # 依赖与打包配置
└── uv.lock               # 离线环境依赖锁定
```

## 三、单元测试与离线验证

在插件根目录下运行单元测试：
```bash
python3 mt-plugin-dev/media.series-dedup/tests/test_dedup.py
```
覆盖测试项包括：
- 零宽脏字符与标点清洗；
- 多种 TMDB 标签格式提取；
- 片名严格全等比对与年份差异比对；
- 链接形态判定与 mixed 混合链拦截安全测试。
