# 影视查重 1.4.3

## 路径及授权

本地扫描直接读取已配置的本地 STRM 目录。云盘删除与整理通过本地 STRM 前缀 → MT 云盘挂载前缀映射，不使用 STRM 内容构造源路径。

在宿主配置 rootBindings 中填写真实授权根 ID 和容器挂载路径，并授予文件读取、删除以及整理所需能力。插件不需要额外服务地址或密钥。

先保存路径映射，再点“测试MT云盘路径映射（只读）”。测试只证明目录可读取，不会执行删除，也不保证删除权限已经授予。

## 槽位与格式

“公共槽”对应规则内部 unmatched=best 的公共比较分桶，仅修改显示名称，不改变评分规则或胜负。未命中且规则选择跳过的条目仍显示“未命中槽位（跳过）”，不会混入公共槽。

视频格式列显示 ISO、MKV 等已识别的目标扩展名；旧快照缺少格式信息时需重新扫描。旧快照评分详情的公共槽标签无需重新扫描。

## 混合处理

重新评分 → 全批次预检及加锁 → MT逐文件删除败者与同名伴随文件 → 核验宿主任务明确成功且源文件消失 → 本地索引指纹复核与清理 → 空目录复核 → 只整理胜者白名单。

未知提交结果不重试；运行中的删除任务需等待后通过“核验续接”核对。不把任务入队视为完成，不把读取错误视为目录为空。旧版本非MT后端未完成记录不会自动转换后端或重放。

## 1.4.4 范围更正

本插件只处理不同作品目录、相同媒体类型及相同TMDB ID的重复组（至少两个去重后的绝对路径）。单目录内部多STRM、混合链接或多版本由STRM查重插件处理，不因命名不标准或链接混合而纳入本插件。

跨目录比较仍按季集及已选多版本槽位隔离；一个分桶若仅来自一个作品目录，不在本插件中判败者。不同槽位不互相竞争。旧单目录快照条目在读取及执行入口失效，不重放旧处理记录。

已核对旧TMDB 9769记录：只有一个作品目录，原评分实际已分为公共槽与iso，均为胜者；错误是纳入范围，而不是这条结果完全没有分槽。1.4.4部署后已确认该条不再出现在当前查询页。107项测试和Python3.12 check/pack通过，未执行真实媒体删除或整理。

## 1.4.8 修复说明
- 混合清理只对无胜者的败者目录记录并清理已知目录图片，按预检指纹复核；未知文件保留并停止整理。
- 已提交任务只核验原引用，续接不重发删除。授权根仅允许读取直接子项以核验子目录消失，仍禁止删除根。
- 清空扫描缓存同时清除自动无年份保护；保留手动/旧版保护项及独立任务日志和锁。下次扫描仍无年份时可再次加入。
- 旧中断流程不会自动恢复。旧记录未预检的目录图片不会自动补入删除清单；需核验后另行确认。


## 1.4.9 败者空壳规则
败者作品目录及子目录完全没有 STRM 或正规媒体文件时，可清理剩余所有附属文件并删除目录，包括字幕、NFO、图片和其他文件。完整读取失败、符号链接、仍有胜者或跳过项时不按败者空壳删除。云盘通过 MT 逐文件任务并核验原引用，不重放删除；本地逐文件复核后移除，再自底向上清理目录。旧中断流程不会随升级自动执行。


## 1.4.10 MT空目录删除参数
MT删除目录要求 recursive=true。适配器仅在完整列举及提交前复核均为空时设置此参数，普通文件仍为false。已有任务引用继续核验，未知提交不重放。旧失败记录不会自动重试。


## 1.4.12 非混合流程复核
所有普通整理和删除入口均在执行时重查当前保护表，旧扫描快照不能绕过扫描后新增的无年份/手工保护。电影与电视剧的保护身份分离。整理分页失败、后续条目无效均在提交前中止；部分已提交而后续结果未知时保留凭据，不自动重发。云盘整目录删除确认的是宿主源目录任务，不保证本地STRM索引同步消失；整理后须重新扫描。
